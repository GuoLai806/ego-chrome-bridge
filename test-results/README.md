## 错误、自主恢复与证据边界

- 填表两次题面关键词过严导致任务脚本停止，同一个DS重新观察后恢复，无人工代填。24题有完整接受值/进度回执；Q11、Q12、Q27–Q30回执被输出截断。脚本中的输入值符合固定资料、最终页面完成，但不叫“30条最终答案均已独立逐字回读”。
- 填表使用实时观察后分支执行的脚本批次，不是严格每题一轮模型请求；不能拿它当一动作一模型的基准。
- KS评论懒加载/滚动位置和截图异常导致多次自主复读补拍。评论来自真实DOM与多次滚动，不是每条都完整显示在一张截图。截图保存为成功也不代表像素映射正确。
- B站遇到CLI参数形状不支持、选择器未匹配、误把新标签搜索当同标签跳转，均根据新回执恢复，没有重放已成功的搜索动作。
- B站普通DOM提取脚本漏读Shadow DOM正文，后来用现有截图和AX快照读到；“容器文本为空”不能直接判断没有评论。
- 等待“至少两个主评论”的脚本对0评论、一个主评论加回复不适用，出现滚到页底后仍重复滚动。这是明确重复开销，不是必须增加新模型的理由。
- 外层Bash的isError=false不能掩盖已捕获/被管道覆盖的命令或定位错误。不用“没有外层错误”宣称零失误。
